# Historial de Actividad

<p align="center">
    <img src="/assets/img/MU9.png" alt="Historial Actividad" width="100%">
</p>

El modulo **Historial de Actividad** permite revisar el registro de acciones realizadas dentro del sistema. Su finalidad es brindar trazabilidad sobre cambios, movimientos y eventos importantes ejecutados por los usuarios o por procesos internos.

## Que permite este módulo

Dependiendo del acceso disponible, este módulo puede permitir:

- Visualizar eventos registrados
- Aplicar filtros de busqueda
- Identificar usuario responsable de una accion
- Revisar fecha y hora de los eventos
- Consultar detalles adicionales del registro

## Ingreso al módulo

Para ingresar:

1. Ubique la opción **Historial de Actividad** en el menu lateral.
2. Haga clic sobre la opción.
3. El sistema mostrara la vista de consulta del historial.

Si no visualiza este módulo, significa que su usuario no cuenta con permiso para acceder al historial.

## Que información muestra

El historial de actividad puede mostrar información como:

- Usuario que realizo la acción
- Descripción del evento
- Tipo de evento
- Módulo o elemento afectado
- Fecha y hora
- Detalles adicionales del cambio

Esto permite revisar la secuencia de acciones ocurridas dentro del sistema.

## Uso de filtros

<p align="center">
    <img src="/assets/img/MU9a.png" alt="Filtro de Historial Actividad" width="100%">
</p>

El módulo puede incluir filtros para facilitar la consulta de eventos. Entre los filtros posibles se encuentran:

- Nombre del log
- Evento
- Descripción
- Usuario responsable
- Tipo de elemento afectado
- Fecha desde
- Fecha hasta

### Recomendación

Use filtros cuando exista gran cantidad de información, especialmente si necesita revisar un evento puntual o una accion realizada por un usuario específico.

## Utilidad del historial

El historial es útil para:

- Seguimiento de cambios
- Control administrativo
- Auditoria interna
- Verificacion de operaciones
- Revisión de incidencias

## Ejemplos de eventos que pueden registrarse

El sistema puede registrar acciones como:

- Creación de usuarios
- Modificación de roles
- Eliminación de permisos
- Asignación de permisos especiales
- Cambios de estado
- Otros eventos relevantes según los módulos activos

## Problemas frecuentes

### No encuentro una acción en el historial

Posibles causas:

- El evento fue filtrado incorrectamente
- El rango de fechas no incluye la acción buscada
- El sistema no registra ese tipo de evento específico
- No se esta consultando el usuario o módulo correcto

### Hay demasiados registros y no puedo ubicar el evento

Se recomienda usar filtros por:

- Fecha
- Usuario
- Descripción
- Tipo de evento

### No puedo ingresar al historial

Posibles causas:

- No tiene permiso para ver logs
- El módulo no esta habilitado para su usuario

## Buenas practicas

- Use el historial para verificar cambios importantes
- Filtre por periodos concretos para facilitar la búsqueda
- No utilice el historial como unica fuente operativa, sino como apoyo de seguimiento
- Revise la fecha y el usuario al analizar un evento

## Importancia del módulo

El historial de actividad aporta trazabilidad y transparencia sobre las acciones realizadas dentro del sistema, lo que ayuda a mejorar control, seguimiento y auditoria.
