# Informe de Agenda

<p align="center">
    <img src="/assets/img/MU7.png" alt="Informe Agendar" width="100%">
</p>

El módulo **Informe de Agenda** permite registrar el informe de actividades realizadas, incluyendo actividades programadas y actividades no programadas.

Este proceso complementa el módulo de agenda, ya que permite documentar la ejecucion real del trabajo realizado.

## Que permite este módulo

Según los permisos del usuario autenticado, este modulo puede permitir:

- Visualizar el formulario de informe
- Registrar actividades programadas
- Registrar actividades no programadas
- Guardar información de seguimiento
- Generar información para reportes posteriores

## Ingreso al módulo

Para ingresar al módulo:

1. Ubique la opción **Informe de Agenda** en el menu lateral.
2. Haga clic en la opción.
3. El sistema mostrara la vista de registro de informe.

Si la opción no aparece en el menu, el usuario no cuenta con permiso para acceder a este módulo.

## Informacion general del informe

El sistema presenta una vista de trabajo vinculada a la fecha actual y al usuario autenticado.

En este proceso se puede registrar informacion relacionada con:

- Actividades programadas
- Actividades no programadas
- Departamento o equipo asociado
- Fecha de actividad
- Detalle del trabajo realizado

## Actividades programadas

Las actividades programadas son aquellas que ya estaban previstas dentro de una agenda registrada previamente.

Dentro del informe, estas actividades pueden ser utilizadas como base para reportar la ejecucion real.

## Actividades no programadas

<p align="center">
    <img src="/assets/img/MU7a.png" alt="Actividades No Programadas" width="100%">
</p>

Las actividades no programadas permiten registrar trabajo realizado que no formaba parte de una agenda previamente planificada.

Este registro es util cuando surge una tarea adicional, extraordinaria o imprevista.

Para registrar una actividad no programada, normalmente se requiere:

- Identificación de la agenda relacionada
- Descripcion de la actividad
- Departamento o equipo
- Fecha

## Guardar el informe

Una vez completada la información:

1. Revise las actividades registradas.
2. Verifique que los datos sean correctos.
3. Guarde el informe.

### Resultado esperado

La información quedara registrada y disponible para procesos posteriores de consulta, reporte o validación.

## Relación con reportes

La información ingresada en este módulo alimenta el módulo de reportes. Por esta razón, los datos registrados aqui deben ser precisos y consistentes.

## Problemas frecuentes

### No puedo ver el módulo Informe de Agenda

Posibles causas:

- No tiene permiso para ver informe de agenda
- El rol no incluye acceso a este módulo

### No puedo guardar una actividad no programada

Posibles causas:

- Faltan campos obligatorios
- La agenda asociada no existe
- El departamento no fue seleccionado correctamente
- La fecha no cumple validaciones del sistema

### El informe no aparece despues en reportes

Posibles causas:

- No fue guardado correctamente
- Falta completar información obligatoria
- El reporte esta siendo consultado con filtros distintos

## Buenas practicas

- Registre la información el mismo día o lo antes posible
- Describa claramente las actividades realizadas
- Diferencie correctamente entre actividades programadas y no programadas
- Revise departamento, fecha y detalle antes de guardar
- Asegure consistencia entre agenda e informe

## Importancia del módulo

Este módulo es clave para reflejar el trabajo ejecutado y mantener trazabilidad entre lo planificado y lo realizado.
