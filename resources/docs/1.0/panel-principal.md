El panel principal permite al usuario visualizar un resumen inicial del sistema despues de iniciar sesión. Desde esta vista se puede identificar información general y acceder rapidamente a los módulos habilitados según el rol y los permisos asignados.

## Que muestra el panel principal

Al ingresar al sistema, el usuario es redirigido al panel principal. En esta pantalla normalmente se visualiza:

- El nombre del usuario autenticado
- El menú lateral con los modulos disponibles
- Accesos a funciones principales del sistema
- Información resumida o indicadores de trabajo, segun la configuracion actual

## Menú lateral

El menu lateral es uno de los elementos mas importantes del sistema. Desde este menu el usuario puede navegar a los modulos que tiene autorizados.

Entre las opciones que pueden aparecer se encuentran:

- Panel de control
- Usuarios
- Permisos
- Roles
- Historial de actividad
- Agendar
- Departamentos
- Tipo de personal
- Informe de agenda
- Reporte de agenda e informe
- Manual

## Importancia de los permisos en el panel

No todos los usuarios visualizan las mismas opciones. El contenido del menú depende de:

- Rol asignado al usuario
- Permisos especiales
- Configuración interna de acceso

Por esta razón, dos usuarios distintos pueden ver menus diferentes aunque ingresen al mismo sistema.

## Para que sirve esta pantalla

El panel principal sirve para:

- Ubicar rapidamente los módulos disponibles
- Iniciar tareas operativas
- Identificar el entorno de trabajo del usuario
- Confirmar que el acceso fue realizado correctamente

## Buenas practicas de uso

Se recomienda al usuario:

- Verificar que el nombre mostrado corresponda a su cuenta
- Identificar los módulos que realmente utilizara
- Informar al administrador si falta alguna opción necesaria para su trabajo
- No intentar operar con cuentas de otros usuarios

## Observaciones

Si el usuario no visualiza algún módulo esperado, esto puede deberse a restricciones de permisos y no necesariamente a un error del sistema.

## Siguiente paso recomendado

Una vez conocido el panel principal, se recomienda continuar con el uso del módulo **Usuarios**, especialmente para personal administrativo o con funciones de gestión.
