# Acceso al Sistema

Esta seccion explica como ingresar al sistema y que aspectos debe considerar el usuario antes de comenzar a trabajar.

Permitir que el usuario conozca el proceso correcto de ingreso al sistema y comprenda que el acceso a módulos y funciones depende de sus permisos asignados.

## Requisitos previos

Para acceder correctamente al sistema, el usuario debe contar con:

- Una cuenta registrada
- Correo electronico valido
- Contrasena activa
- Permisos o rol asignado
- Acceso a la URL del sistema

## Pantalla de inicio de sesión

La pantalla de acceso contiene los siguientes elementos:

- Logo institucional
- Titulo de inicio de sesión
- Campo de correo electronico
- Campo de contraseña
- Boton para iniciar sesión

En algunos entornos tambien puede existir acceso a recuperacion de contraseña o registro de usuarios, dependiendo de la configuración habilitada.

## Pasos para iniciar sesión

1. Abra la URL del sistema en su navegador.
2. Ingrese su correo electronico en el campo **Email**.
3. Ingrese su contraseña en el campo **Contraseña**.
4. Presione el boton **Iniciar Sesión**.

Si los datos son correctos, el sistema redireccionara al usuario al panel principal.

## Resultado esperado

Despues de iniciar sesión correctamente, el usuario debera:

- Visualizar su nombre en el menu lateral
- Acceder a los modulos que le correspondan segun permisos
- Ingresar al panel principal del sistema

## Acceso según permisos

El sistema controla la visibilidad y acceso de módulos mediante roles y permisos. Esto significa que:

- Algunos usuarios podran ver mas opciones en el menú
- Otros usuarios tendran acceso limitado
- Una opción puede estar visible pero ciertas acciones internas pueden estar restringidas
- Si un módulo no aparece, normalmente se debe a falta de permisos

## Recomendaciones de seguridad

Para proteger su cuenta y la información del sistema:

- No comparta su contraseña
- No deje la sesión abierta en equipos compartidos
- Cierre sesión al finalizar
- Informe cualquier comportamiento inusual al administrador

## Problemas frecuentes de acceso

### No puedo iniciar sesión

Revise los siguientes puntos:

- Correo correctamente escrito
- Contraseña correcta
- Conexión estable
- Usuario activo dentro del sistema

### Ingreso al sistema pero no veo ciertos módulos

Esto puede deberse a:

- Rol no asignado
- Permisos insuficientes
- Acceso restringido por configuración administrativa

### Veo el módulo pero no puedo ejecutar acciones

Esto ocurre cuando:

- El usuario tiene permiso de visualización pero no de edición
- La accion requiere un permiso adicional
- El rol no incluye todas las operaciones necesarias

## Cuando contactar al administrador

Solicite ayuda al administrador si presenta alguna de estas situaciones:

- No puede ingresar al sistema
- Su usuario no aparece activo
- No visualiza opciones necesarias para su trabajo
- Sus permisos parecen incorrectos
- Necesita acceso a un nuevo módulo
