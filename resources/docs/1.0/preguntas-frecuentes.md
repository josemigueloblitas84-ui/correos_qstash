Esta sección reune respuestas a dudas comunes que pueden surgir durante el uso del sistema. Su finalidad es ayudar al usuario a resolver situaciones frecuentes sin necesidad de asistencia inmediata.

## No puedo iniciar sesión

Revise lo siguiente:

- Que el correo este correctamente escrito
- Que la contrasena sea correcta
- Que el usuario se encuentre activo
- Que este accediendo a la URL correcta del sistema

Si el problema persiste, contacte al administrador.

## Ingreso al sistema pero no veo algunos módulos

Esto generalmente significa que su cuenta no tiene permisos para visualizar esos apartados.

Posibles causas:

- Rol no asignado correctamente
- Permisos insuficientes
- Configuración especial del usuario

## Puedo ver un módulo, pero no puedo crear, editar o eliminar

Esto sucede cuando el usuario tiene permiso de visualizacion, pero no permisos de accion.

Por ejemplo, puede tener acceso para consultar usuarios, pero no para modificarlos.

## No aparece la opción Usuarios, Roles o Permisos

Posibles causas:

- Su rol no incluye esos modulos
- No cuenta con permisos administrativos
- El acceso esta restringido a personal autorizado

## No puedo guardar una agenda

Revise si:

- Completo todos los campos obligatorios
- Las fechas son validas
- La fecha final no es menor a la inicial
- Las fechas corresponden al mismo mes, segun la validación actual del sistema

## No puedo registrar una actividad no programada

Verifique que:

- Exista una agenda relacionada
- Haya seleccionado correctamente el departamento o equipo
- La fecha sea valida
- Todos los campos requeridos esten completos

## No encuentro datos en los reportes

Antes de asumir que existe un error, revise:

- El rango de fechas seleccionado
- El equipo o departamento filtrado
- El tipo de consulta elegida
- Si realmente existen registros en ese periodo

## No puedo validar informes

Esto puede deberse a:

- Su usuario no tiene habilitada la validacion
- El informe ya fue validado
- No cuenta con el perfil necesario para esa acción

## No puedo ingresar al historial de actividad

Posibles causas:

- No tiene permiso para ver logs
- El módulo no esta habilitado para su usuario

## Que hago si visualizo información incorrecta

Se recomienda:

- Verificar primero si el filtro aplicado es correcto
- Revisar si esta usando la cuenta adecuada
- Informar al administrador si la inconsistencia persiste

## Que hago si falta un boton o una opción del menu

Lo mas probable es que se trate de un tema de permisos.

En ese caso, debe solicitar al administrador que revise:

- Rol asignado
- Permisos del usuario
- Permisos especiales adicionales

## Recomendación final

Antes de reportar un problema, procure verificar:

- Si ingreso con el usuario correcto
- Si seleccionó bien los filtros
- Si el módulo esta habilitado para su perfil
- Si completo correctamente los datos requeridos
