# Manual de Usuario

Bienvenido al manual de usuario del sistema de gestión de permisos, roles, usuarios, agenda, informes y reportes de **Fundación Unifranz**.

Este manual esta dirigido a usuarios operativos, administrativos y responsables de control que utilizan el sistema para registrar informacion, administrar accesos y consultar reportes de trabajo.

## Presentación del sistema

El sistema fue desarrollado para centralizar procesos importantes de la organizacion, permitiendo controlar el acceso de usuarios y registrar actividades operativas de manera ordenada.

Mediante este sistema es posible:

- Administrar usuarios del sistema
- Administrar roles y permisos
- Registrar agendas de trabajo
- Registrar informes de actividades
- Consultar reportes
- Revisar historial de actividad

## Objetivo del sistema

El objetivo principal es facilitar la gestión interna de información y acceso a módulos, asegurando que cada usuario visualice unicamente las opciones autorizadas según su rol o permisos asignados.

Esto permite mejorar:

- El control de acceso
- La organizacion del trabajo
- El registro de actividades
- La consulta de informacion historica
- La trazabilidad de acciones realizadas en el sistema

## A quien esta dirigido

Este manual esta dirigido a:

- Administradores del sistema
- Personal encargado de gestionar usuarios
- Personal que registra agenda
- Personal que registra informes
- Usuarios con acceso a consultas y reportes
- Responsables de validación y seguimiento

## Módulos principales del sistema

Los módulos disponibles pueden variar segun el rol y los permisos de cada usuario. Entre los módulos principales se encuentran:

- Panel de control
- Usuarios
- Permisos
- Roles
- Historial de actividad
- Agendar
- Departamentos
- Instituciones
- Sedes
- Tipo de personal
- Informe de agenda
- Reporte de agenda e informe
- Manual

## Consideraciones importantes

Antes de utilizar el sistema, tenga en cuenta lo siguiente:

- No todos los usuarios ven las mismas opciones en el menú
- Algunas acciones solo estan habilitadas para determinados roles
- Ciertos botones o modulos pueden ocultarse segun los permisos asignados
- La información registrada en agenda e informes impacta directamente en los reportes

## Recomendaciones generales

Para un mejor uso del sistema se recomienda:

- Verificar los datos antes de guardar
- Trabajar siempre con su cuenta personal
- No compartir credenciales de acceso
- Cerrar sesion al finalizar el trabajo
- Informar al administrador si detecta accesos incorrectos o permisos faltantes
